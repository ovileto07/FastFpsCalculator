What is an FPS calculator?

An FPS calculator is a planning tool that estimates frames per second before you launch a game. It is useful when checking whether a PC can handle a game, choosing a graphics card, or deciding whether an upgrade is worth the money.

What do I need to enter?

Select your processor, graphics card, game and resolution. You can then adjust graphics quality, RAM and other available options. The result is shown as an estimated FPS range rather than a promise of an exact in-game number.

Why can real FPS be different?

Actual frame rate changes with game patches, drivers, background programs, temperatures, memory configuration and the exact scene being rendered. Use the result as a comparison and planning estimate.
